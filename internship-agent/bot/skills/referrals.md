# Referrals

1. Name the company and team/role.
2. Suggest search targets, not fake people:
   - University alumni at the company (LinkedIn school filter)
   - Recruiter titles: `University Recruiter`, `Early Career`, `Intern Program`
   - Team titles matching the posting (e.g. `Software Engineer, intern host`)
3. Give exact LinkedIn/Handshake search strings.
4. Draft a short ask (alumni vs cold recruiter). No fake names or emails.
5. If the user already named a person, draft only that message.
6. Do not scrape LinkedIn. You have no people API in v1.
